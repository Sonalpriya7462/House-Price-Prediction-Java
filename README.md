
🏠 House Price Prediction System (Java)

📌 Overview

This is a simple Java-based project that predicts house prices based on user input such as area, number of bedrooms, and bathrooms.

⚙️ Technologies Used

- Java
- Basic Regression Formula

🚀 How to Run

1. Make sure Java is installed
2. Open terminal in project folder
3. Run the following commands:

javac Main.java
java Main

🧠 Working

The system takes input from the user:

- Area (in square feet)
- Number of bedrooms
- Number of bathrooms

Then it calculates the estimated house price using the formula:

Price = (Area × 50) + (Bedrooms × 10000) + (Bathrooms × 5000)
